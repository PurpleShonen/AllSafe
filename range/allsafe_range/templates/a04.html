1. Password storage

Unsalted MD5. /a04/export returns the whole user table, hashes included. 

curl -s http://range.allsafe.local/a04/export | jq -r '.users[] | "\(.username):\(.password_md5)"' > hashes.txt
hashcat -m 0 -a 0 hashes.txt rockyou.txt

2. Password reset token

The token is md5(email + unix_minute). No secret, no entropy, and it is returned in the response body over plain HTTP.

Request a reset token

3. Hardcoded signing key

CWE-798 — the session signing key is a literal in config.py:

SECRET_KEY = "{{ secret_key }}"

Anyone holding the source can mint a session cookie for any user. Rotating it is not enough on its own; it has to stop living in version control.

What the logs should show

  • app.log — credential_material_exported at CRITICAL
  • app.log — password_reset_token_issued with the token itself
  • app.log — password_reset_completed for an account the requester does not own
  • Detection idea: a reset issued and completed within seconds, from one IP, for an account that never signed in
